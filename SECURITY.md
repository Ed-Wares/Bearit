# Security Policy

## Supported Versions

We currently provide security updates for the following versions of Bearit:

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Bearit, please **do not open a public issue**. 

Instead, please report it privately by sending an email to:
**EdWaresApp@gmail.com**

Please include the following information in your report:
- A description of the vulnerability.
- Steps to reproduce the issue.
- The version of Bearit you were testing.
- Any potential impact you foresee.

You should expect a response within 48 hours acknowledging receipt of your report. We will then work with you to assess the vulnerability and develop a patch before disclosing it publicly. Thank you for helping keep Bearit secure!
